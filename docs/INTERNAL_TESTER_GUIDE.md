# Thyroid Echo — first internal tester guide

Thank you for trying Thyroid Echo. The goal of the first internal test is not to test every screen mechanically. Use the app the way you naturally would and note anything that feels confusing, slow, repetitive, or easy to miss.

## First day

1. Install Thyroid Echo from the Google Play internal-test link.
2. Complete onboarding.
3. Add your first name only if you want personalized greetings.
4. Choose the thyroid condition you are tracking.
5. Add medication details if useful; the medication fields are optional.
6. Set a medication reminder if you want to test notifications.
7. Complete a normal daily check-in.

## During normal use

Pay particular attention to:

- whether the Today screen makes it obvious what to do next;
- whether a check-in feels quick enough to use every day;
- whether the symptoms Yes/No question is clearer than showing the whole symptom list immediately;
- whether symptom labels/descriptions make sense;
- whether the sliders and buttons are comfortable to use;
- whether the History screen tells you enough without becoming cluttered;
- whether reminders arrive when expected and stop being useful after medication has already been logged;
- whether anything feels medically judgmental or as though the app is trying to diagnose you.

## Optional features

In the Medication screen, try **Optional features** if you are interested in them. You can turn on/off:

- quick context tags;
- weight tracking;
- expanded thyroid labs (TPOAb, TgAb, TRAb).

Turning a feature off should hide its input without deleting previously saved entries.

## Lab and report test

If you have a real lab result available, enter it exactly as printed — including its unit/reference range — then check the doctor report. Thyroid Echo should display what you entered without lab interpretation.

You can also create a test PDF and make sure Android offers normal sharing options.

## Please report

A useful bug report can be very short. Include:

- what you were trying to do;
- what you expected;
- what actually happened;
- a screenshot if it helps;
- whether closing/reopening the app changed anything.

Also report subjective friction such as:

- “I didn't know where to tap.”
- “This wording is confusing.”
- “There are too many steps here.”
- “I expected this to remember something.”
- “I don't understand this field.”
- “I wish this were optional.”

That usability feedback is just as important as a crash.

## Safety note

Thyroid Echo is a tracking journal. It does not diagnose thyroid disease, interpret labs, or recommend medication changes. Medical questions should still go to an appropriate healthcare professional.
