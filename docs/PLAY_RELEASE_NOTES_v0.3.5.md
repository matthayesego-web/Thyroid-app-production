# Thyroid Echo v0.3.5 — Internal Test 2

## Suggested Play release name

`Thyroid Echo v0.3.5 – Internal Test 2`

## Suggested release notes

- Redesigned navigation: Today, Journal, Medication, Insights, and Settings
- New dedicated Settings area for personalization, accessibility, optional features, privacy, and data tools
- Medication screen is now focused only on medication, reminders, and dose history
- Trends, labs, and doctor reports are grouped together under Insights
- Added password-protected encrypted backup and restore for moving or safeguarding local thyroid records
- Backup restore is merge-safe and does not erase unrelated local records
- Refined visual styling and screen headers for a cleaner, more consistent interface
- Preserves existing local journal storage across normal Play updates

## Internal test priorities

1. Update from v0.3.4 through Google Play without uninstalling; verify existing check-ins, labs, medication history, and preferences remain.
2. Create an encrypted backup and save the `.tebackup` file somewhere accessible.
3. Restore that backup on a second test device when available and verify record counts/content.
4. Confirm the new five-tab navigation feels obvious without instructions.
5. Verify reminders still work after an app update and after restoring a backup.
